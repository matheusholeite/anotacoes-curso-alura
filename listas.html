Exemplo de listas

Lista ordenada

  1. Colcar a farinha
  2. Colocar o leite
  3. Colocar os ovos
  4. Colocar o fermento
  • Para adicionar uma lista ordenarna usa-se a as tags ol e li, a ol é para indicar que há uma lista abaixo e o li é o tipo de lista. Por padrão, a lista vem com o tipo de numeração para as listas, mas é possível alterar iso na tag ol, usando a propriedade "type", podendo alterar para número "1", letra "a" ou outro. Pode-se usar outra propriedade, "start", para indicar ao navegador a partir de qual item a lista deve iniciar, por exemplo, em itens numéricos, se colocar "start='5'", a lista começará do número 5 e não 1.

Lista desordenada

  • Comprar produto de limpeza
  • Comprar comida
  • Comprar remédios:
    • Atena
    • mãe
  • Comprar ração
  • Para adicionar uma lista desordenada usa-se a tag "ul". Essa tag é usada qaundo não há necessidade de seguir uma ordem. Assim como na lista ordenada, é possível alterar os ícones da lista com a propriedade type. É possível adicionar uma lista dentro de outra lista, apenas colocar a tag ul ou ol dentro da tag li.
