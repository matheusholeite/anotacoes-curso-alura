O <header> é a tag usada para informar ao navegador que esse conteúdo está no cabeçalho da página.

Obs: o navegador não compreende os caracteres especias se forem escritos diretamente como caractere, e sim como uma tag, então, para escrever um caracetere especial é necessário informar um código, chamado de "entidade". São códigos HMTL que começam com & e terminam com (;), para saber quais códigos para determinado caractere especial, melhor pesquisar no Google.

Obs II: Para escrever uma tag ou outro comando em texto, além de se usar o código de entidade para escrever o caractere especial, pode-se usar também a tag <code>, para formatar a parte do texto que tem a escrita dos códigos, como as tags.

HTML semântico e boas práticas de layout.

Seções

Tags semânticas são tags que declaram exatamente sua função ao navegador.

Ex: <header>, <body>, <main>, <footer>.

A tag <main> é onde todo o conteúdo principal da página se encontra. É aqui que são inseridas as seções, textos e demais elementos principais de navegação da página. Não é indicado colocar tags como <header> ou <footer> aqui.

Aqui usa-se tags como <section>, para indicar ao navegador que essa é uma seção.

Segunda Seção

As seções são muito usadas para separar e organizar o conteúdo dentro do <main>. Além dos textos, é possível inserir links e imagens para deixar tudo organizado.

Primeiro Link da seção.

A tag <article> é usada para indicar ao navegador que há uma seção de artigo, e funciona da mesma forma que a seção comum.

Tags semânticas são sempre indicadas para desenvolver o site e deixar organizado, mas é possível usar tags não semânticas para organizações também. A tag <div> é um exemplo de tag não semântica, ela é uma seção "genérica", é usada para informar ao navegador que foi separado um espaço ali, mas o navegador não sabe direito qual tipo de espaço, ao contrário da <section>, que por ser semântica, o navegador sabe exatamente que o espaço informado é para uma seção de conteúdo.

Outro exemplo de tag não semântica é <span>, usada para destacar alguma parte do texto para estilizar.

O <footer> é usado para deixar informações adicionais da página, como informações de contatos, links de redes sociais, endereço e e-mails de contato.
