Links

Acesse a Alura
  • Com as tags de link pode-se inserir o caminho ou direcionamento para outra página, interno ou externo. A tag "a" é usada para isso, adicionando a propriedade "href", ou seja, referência. Por padrão, o link abre na mesma aba, mas uma boa prática é deixar que o link abra em uma outra aba. Para isso, usa-se a propriedade "target" dentro da tag "a". Dentre as opções, usa-se o comando "_blank" para forçar o navegador a abrir o link em outra aba. Além dessas propriedades, pode-se usar a propriedade "rel", que significa relacionamento, é apenas para indicar aos metadados com a relação do link com o site raiz, se é interno ou externo.
